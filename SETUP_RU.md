# Как запустить и сдать задание

## 1. Посмотри сайт — 2 минуты

Распакуй весь архив. Открой `index.html` двойным кликом.
Имя, фотография, email и GitHub взяты из твоей прежней работы: Alibek Burakhanov, qlibeek.
При необходимости поменяй текст в `index.html`. Прочитай три решения в README и поправь формулировки под себя.

## 2. Создай новый репозиторий — 2 минуты

На GitHub нажми **+ → New repository**.

- Название: `iwamad-sis1-portfolio`
- Видимость: **Public**
- Не добавляй README, .gitignore и лицензию: проект и история уже есть в архиве.

Не загружай файлы через Upload files: тогда три подготовленных коммита не попадут на GitHub.

## 3. Отправь проект — 3 минуты

Открой распакованную папку `iwamad-sis1-portfolio` в VS Code.
Выбери **Terminal → New Terminal**. Проверь, что терминал открыт именно в этой папке.

```powershell
git log --oneline
git remote add origin https://github.com/qlibeek/iwamad-sis1-portfolio.git
git push -u origin main
```

`git log` должен показать три осмысленных коммита. История находится в папке `.git`, включённой в архив: сохраняй её при распаковке.
Если GitHub запросит вход, авторизуйся в своём аккаунте. Пароль аккаунта вводить в Git не нужно.
Если изменил код перед отправкой, сначала сохрани изменения:

```powershell
git add .
git commit -m "Personalize portfolio content"
```

## 4. Включи GitHub Pages — 2 минуты

В новом репозитории открой **Settings → Pages**:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**
- Нажми **Save** и дождись окончания публикации.

Ожидаемый адрес: https://qlibeek.github.io/iwamad-sis1-portfolio/
Точный опубликованный адрес возьми из Settings → Pages.

## 5. Проверь перед сдачей — 5 минут

Открой опубликованный адрес в приватном окне браузера.

1. Нажми все три пункта меню.
2. Переключи тему и проверь фон, карточки, текст и поля формы.
3. Отправь пустую форму: у каждого поля появится своя ошибка.
4. Заполни имя и сообщение, введи `wrong-email`: появится другая ошибка email.
5. Введи правильный email: появится сообщение об успехе. Сообщение никуда не отправляется.
6. Нажми Tab: у ссылок, кнопок и полей должна быть видимая рамка фокуса.
7. В DevTools включи ширину 375px, затем 1200px. На 375px все основные блоки в одну колонку; на 1200px фото рядом с текстом, проекты в три колонки, контакт в две. Проверь отсутствие горизонтальной прокрутки.
8. Открой ссылки трёх проектов. Они ведут на исходники реальных учебных веток. У Week 04 также есть ссылка на работающий сайт.

## 6. Отправь два адреса

В задании выбери **+ Add work → Link** дважды:

1. https://github.com/qlibeek/iwamad-sis1-portfolio
2. https://qlibeek.github.io/iwamad-sis1-portfolio/

Не сдавай до окончания публикации: второй адрес начинает работать только после GitHub Pages deployment.

## Что объяснить преподавателю

- `index.html`: семантическая структура и три раздела; ссылки меню используют `#about`, `#projects`, `#contact`.
- `styles.css`: цвета, шрифты и интервалы заданы переменными. Media query при 760px меняет сетки на одну колонку.
- `script.js`: `applyTheme()` меняет `data-theme`; обработчик кнопки переключает тему и сохраняет предпочтение.
- `validateField()` сначала проверяет пустое поле, затем формат email. Обработчик submit вызывает `preventDefault()`, показывает ошибки или успех.
- У прежних проектов могут быть React и TypeScript: это ссылки на прошлые работы. Само новое портфолио написано без фреймворков.

Сайт, репозиторий и Pages — разные этапы: код и локальные коммиты подготовлены; публичный репозиторий и Pages нужно включить в своём GitHub аккаунте.
